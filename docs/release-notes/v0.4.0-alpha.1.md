# ThIDE 0.4.0-alpha.1

First pre-release of the 0.4 line. Covers everything since **0.3.0-alpha.2** (2026-07-29):
about 470 commits, including 78 new features and more than 200 fixes.

> **Alpha.** Back up your survey projects before you try it on real data. The builds are not code-signed,
> so Windows SmartScreen and macOS Gatekeeper will warn the first time you open them.

## Highlights

- **Templates and new-file flows.** You can create files from templates with **File ▸ New File**.
  **File ▸ New from Template…** creates a whole project from one of three built-in project
  templates, and **Tools ▸ New trip** creates a trip file that is already filled in and tied into
  the project. The editor has snippets with tab-stop fields, which you can layer per project, and a
  Quick Export block can be saved as a reusable thconfig fragment.
- **Automation.** Projects can define hooks (scripts that run on build and file events), tasks
  with problem matchers (so their errors appear as diagnostics), and macros of tool calls, which
  show a preview before they run. Several thconfigs or exports can be built in one batch. Commands
  defined by a project only run after you trust the workspace. All of this is managed from the new
  **Automation** panel.
- **Project-wide fixes.** You can fix one problem, or every problem with the same code, in one
  step. New commands: **Add unreferenced scraps to maps**, **Suggest equates**, and **Format all
  files**. Each one shows its changes first, and multi-file edits are all-or-nothing and undo as a
  single step.
- **Link survey file.** A new dialog, with station and survey pickers and a live preview, writes
  the `input` and `equate` lines that tie a survey file into the project.
- **3D viewer.** Uses the new **Therion.CaveView** library, built on a fork of CaveView.js. Adds a
  crosshair, a close-up for **Show in 3D**, and an **export to a stand-alone web page**.
- **Import.** Shot tables can now be imported. TopoDroid survey headers (team, dates, units, cs,
  fix, entrance) and sketches are read. Survex and Compass import is more accurate.
- **Command-line tools.** New `therion-cli new`, `build`, `import`, `report` and `format --check`
  commands. New `therion-mcp call` and `therion-mcp macro` commands, plus an LM Studio preset.
- **AI assistant.** Adds a skill pack, a setting for what data the assistant may send to the model,
  and preview calls that run without asking.
- **Localization.** Library diagnostics, dialogs built in code, status lines and the 3D viewer now
  follow the UI language, including when you switch it while the app is running. English and
  Romanian use consistent terms and correct plurals.

## New features

### Editor
- Snippet expansion with tab stops, inserting from the context menu, and snippet and keyword
  completion over LSP.
- Paste as shot data (into the survey's centreline), renumber stations, normalise project.
- **Shift+F12** lists references. The rename, renumber, format and normalise previews show the
  change itself.
- Replace All asks for confirmation. Multi-file writes undo as one step.
- Warns about `\` in thconfig `export -output` paths and offers to rewrite them with `/`.

### Workspace and project
- A project-local config folder (`.thide`). Hidden folders are skipped when thconfig files are
  discovered.
- Surveys and stations are scoped workspace-wide, with formatting for `@` references and
  workspace-wide pickers.
- Station and survey lists sort in natural order.
- An incoming folder: survey exports are routed into it and checked to be stable before use.

### Build
- Builds take a full entry path and support `-q` and `-l`. The build result reports how the build
  ended, and compile-on-save follows every save.
- Outputs are reconciled with Therion's log.
- The global **Ctrl+Alt+B** build hotkey is now opt-in.

### Scaffold and import
- Copies a TopoDroid survey's sketches into the project and checks them for conflicts. Lists the
  files a plan's exports will write. Adds a catalogue of named export presets.
- Lists any inputs and imports that could read files outside the survey's directory.

### UI and app
- Core commands are in the menus and the command palette.
- Shortcut edits are staged, and the app asks before taking a key combination that is already in
  use.
- Crash-recovery offers are pinned above the editor, and destructive resets ask for confirmation.
- Accessible names and automation ids on controls, and an opt-in in-app UI automation server.
- The 3D viewer shows its developer buttons only when web developer tools are enabled.

### Blender and licensing
- The Blender export exposes centerline degree, leg shape and the reduced graph.
- The Structural and Blender modules are now licensed under MPL-2.0.

## Notable fixes

- **Saving and encodings.** Saves are atomic and keep the file's encoding. ThIDE refuses to save
  bytes it could not decode. Writes through symlinks keep file modes and roll back completely if
  they fail. Files are never marked saved when they were not.
- **Crash recovery.** Recovery copies are kept per running instance and are only deleted once you
  restore or discard them. A recovered buffer opens beside newer unsaved edits instead of over them.
- **Parser and semantics.** Strings end at the line break. Mixed and lone-CR line endings are
  handled. Handling is fixed for sexagesimal fix coordinates, ETRS systems, `calibrate`, `@` paths
  relative to the survey they appear in, equates in loop closure and leads, and the cavern
  statistics wording of Survex 1.4. Strict mode now raises the remaining lenient checks to errors.
- **Statistics and exports.** Statistics follow equates and skip surface legs and splays.
  GeoJSON, GPX and XML exports are valid for any point name.
- **MCP server and agent safety.** Agents cannot write to `.thide` (in any letter case, or through
  links), cannot overwrite sources or files with unsaved changes, and cannot overwrite concurrent
  writes. Builds that run thconfig system commands ask first, and headless builds refuse them
  unless `--allow-system-commands` is passed.
- **Search.** Replace in Files is safe and consistent with Find All. It skips files it cannot read
  back without loss and does not follow folder symlinks.
- **Platform.** Absolute paths passed on the command line open on Linux and macOS. On Windows,
  programs are started by full path. A failed move to the trash no longer deletes the file
  permanently. File associations use the AppImage path.
- **Layout and docking.** Windows fit a 1366×768 laptop. Floated panels can be docked back, and
  toasts stay clear of the tool tab strips and the 3D viewer.

## Changes for developers and integrators

- **Moved into libraries.** Quick fixes, rename planning, fix-all, encoding-preserving file I/O,
  and the thconfig export editor now live in `Therion.Workspace`. The consumer-visible changes of
  `Therion.Workspace`, `Therion.Build`, `Therion.Blender` and `Therion.CaveView` are listed in
  their changes files.
- **Builds and CI.**
  - The app still targets **.NET 8**. CI also builds and tests on **.NET 10**.
  - Both UI test suites run unattended, and the in-app suite blocks merges.
  - MessagePack is updated to 2.5.307. The unused Superpower and CodePages packages are removed.
- **Rename.** **File ▸ New Project…** is now **File ▸ New from Template…**.
