Reference data for GeoMagneticModelReferenceTests, copied unchanged from NOAA NCEI's WMM2025 coefficient
package (https://www.ncei.noaa.gov/products/world-magnetic-model/wmm-coefficients, WMM2025COF.zip,
dated December 17, 2024). NOAA/NCEI publish the World Magnetic Model as public-domain data.

  WMM2025.COF              the WMM2025 coefficients (identical to WMM.COF in the package)
  WMM2025_TestValues.txt   NOAA's published test values: 100 points, 2025.0-2029.5, altitude 0-100 km

  WMM2025_TEST_VALUES_short.txt
                           the 12-point table NOAA prints with the model (WMM2025_TEST_VALUES.txt on the
                           same page), values rounded to 0.1 nT and 0.01 degree

Do not edit either file; the tests compare the model's output with the table.
